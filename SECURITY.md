# Security Policy

## Supported versions

Security updates are maintained on the default branch and, once releases are published, the latest published release. Older releases are not supported unless a broader policy is announced.

## Report a vulnerability privately

Do not open a public GitHub issue for a suspected vulnerability in `@tavojs/mcp`. Send a private report to support@tavojs.dev.

Please include:

- the affected version or commit and whether the issue involves stdio or HTTP transport;
- a minimal reproduction with the prerequisites and observed behavior;
- the expected security impact and affected boundary; and
- any suggested mitigation, if known.

Remove secrets, personal data, and unnecessary internal information from the report and reproduction.

## Safe testing and coordinated disclosure

Test only systems and data you own or are authorized to use. Do not disrupt production services, degrade availability, access other people's data, retain sensitive data, or use a vulnerability beyond what is necessary to demonstrate it safely. Stop testing and report promptly if you encounter sensitive data or risk harming a system.

Please give the maintainers a reasonable opportunity to investigate and address the report before public disclosure. Coordinate publication details with the maintainers so users can update safely. No fixed response or resolution time is promised.
